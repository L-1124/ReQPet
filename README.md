# ReQPet
ReQPet (fork of QPet Companion) 是基于 Kotlin 与 LSPosed 框架开发的手机 QQ 宠物管理模块。

---

## 功能特性

### 1. 设置页原生集成与主题自适应
- **分类设置**：在手机 QQ 设置中提供二级管理入口，涵盖任务养成、宠物照料、社交互动、对决挑战、福袋领取、调度策略、日志诊断与模块设置。
- **日夜模式同步**：自动跟随手机 QQ 当前日间与夜间模式，切换明亮与深色主题。
- **运行诊断**：提供实时运行状态、引擎诊断指标以及分级日志查看。

### 2. 学园课程与职业场所动态同步
- **学园阶段识别**：自动读取学园阶段（初级、中级、高级、进修）及三维属性，支持按阶段、科目与课时灵活配置。
- **职业场所同步**：动态识别职业小镇全量工作场所与解锁状态，支持工时档位配置与未解锁项拦截。
- **好友雇佣筛选**：支持按昵称或 QQ 号配置雇佣白名单，并在打工派遣时优选三维资质最高的好友。

### 3. 日常照料与自动任务循环
- **阈值化补给**：支持自己与好友小宠的饥饿度与清洁度独立阈值管理，低于设定值自动补充。
- **任务互斥调度**：自动协调学习、打工与冒险任务，支持任务到期自动对账与收益结算。
- **社交与地面奖励**：自动扫描并拾取家园福袋金币，支持到访记录回访与好友宠物互动。
- **拟人化与静默调度**：内置随机休眠与夜间/熄屏静默时段，降低高频发包风险。

### 4. 手动指令与防误触确认
- **即时操作**：支持手动发起全套巡检、任务召回、日常照料、福袋领取与社交互动。
- **二次确认**：对任务召回等中断性操作提供弹窗二次确认，防止误触。
